# Rocket Life (PWA)

แอปติดตามงานส่วนตัวสำหรับ iPhone ข้อมูลเก็บในเครื่องเท่านั้น ใช้ออฟไลน์ได้ และสำรองเป็นไฟล์ JSON ได้

## ไฟล์
- `index.html` หน้าแอป
- `styles.css` ชุดสี/คอมโพเนนต์ตามดีไซน์ (โหมดสว่าง + มืดตามระบบ)
- `app.js` ตัวแอป (รวมจาก `src/1-core.js` · `src/2-views.js` · `src/3-sheets.js`)
- `sw.js` ใช้ออฟไลน์ · `manifest.webmanifest` + `icons/` สำหรับติดตั้งบนหน้าจอโฮม

ถ้าแก้ไฟล์ใน `src/` ให้รวมใหม่ด้วย `cat src/1-core.js src/2-views.js src/3-sheets.js > app.js`
และเปลี่ยนชื่อ `CACHE` ใน `sw.js` (เช่น `rocketlife-v2`) เพื่อให้ iPhone โหลดเวอร์ชันใหม่

## ลองในเครื่อง
```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 (ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์)

## ติดตั้งบน iPhone
1. อัปไฟล์ทั้งโฟลเดอร์ขึ้นโฮสต์ที่เป็น HTTPS (เช่น GitHub Pages, Netlify, Cloudflare Pages)
2. เปิดลิงก์ด้วย Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## กฎที่แอปทำให้อัตโนมัติ (ตอนเปิดแอป)
- to-do / งานย่อยที่ไม่เสร็จ เลื่อนมาวันนี้เอง
- โปรเจกต์ที่กด "เสร็จแล้ว" วันถัดไปย้ายเข้า Archive เอง
- ศุกร์เป็น WFH บนปฏิทิน ยกเว้นวันที่เช็กอินเป็นออฟฟิศ/นอกสถานที่
- ชั่วโมงทำงาน = เช็กเอาต์ − เช็กอิน (ไม่มีนาฬิกาจับเวลาระหว่างวัน)

ตั้งค่า → "ใส่ข้อมูลตัวอย่าง" เพื่อดูหน้าตาแอปพร้อมข้อมูล
